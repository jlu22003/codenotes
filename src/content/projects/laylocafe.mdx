# Laylo Cafe Website

<ProjectHero id="laylo-cafe" />

## Context
[laylocafe.com](https://laylocafe.com)

The client needed a Shopify storefront, plus the ability to manage product updates independently after launch, without relying on ongoing developer support.

## Implementation
Architected an AI-assisted Shopify theme development workflow (21st.dev MCP, Higgsfield MCP, and Impeccable — AI coding tools used to speed up component scaffolding and design iteration) and built custom Liquid components for the storefront.

## Impact
The client can independently manage product updates post-launch, with no engineering involvement required.
